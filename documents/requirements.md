# 要件定義

## 1. 基本要件

- 動画共有プラットフォーム
- リラックス感のあるユーザー体験
- グループ内でのコミュニケーション促進

## 2. 機能要件

### 2.1 動画管理

- 動画アップロード機能（50MB 制限）
- YouTube 動画 URL 共有機能
- 動画再生機能
  - 音量調節
  - 全画面表示
  - 再生速度変更
  - プレビュー表示
  - ダウンロード機能

### 2.2 ソーシャル機能

- いいね機能（1 回のみ）
- コメント機能
- 非表示設定機能

### 2.3 カテゴリー管理

- カテゴリーの追加
- カテゴリーの更新
- カテゴリーの削除

### 2.4 ユーザー管理

- ユーザー登録
- ユーザー更新（管理者権限）
- ユーザー削除
- Google 認証
- アバター管理
  - 登録
  - 変更
  - 削除

### 2.5 その他

- ログアウト機能
- ナビゲーション機能

## 3. 技術要件

### 3.1 フロントエンド

- Next.js (React)
- TypeScript
- Tailwind CSS

### 3.2 バックエンド

- Supabase

### 3.3 データベース

- PostgreSQL

### 3.4 デプロイ

- Vercel

## 4. セキュリティ要件

- ユーザー認証
- 権限管理
- データ保護
